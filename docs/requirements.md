# 需求分析（D3 定稿稿）

> 项目：基于大语言模型的代码审计系统 ｜ 版本：v1.0-draft ｜ 撰写：全体（9/7 评审定稿）
> 上游依据：申报书「研究内容」四条 +「拟解决的关键问题」四条

## 1. 目标用户与使用场景

| 用户 | 场景 | 关键诉求 |
|---|---|---|
| 学生开发团队 | 课程项目/大创代码提交前自查 | 免部署、命令行即跑、报告看得懂 |
| 小型团队 Tech Lead | Code Review 前的预筛 | 批量审 PR 涉及文件、误报少、可解释 |
| 使用 AI 生成代码的开发者 | Vibe Coding 产物质量把关 | 识别"能跑但有坑"的逻辑/安全隐患 |
| 安全初学者（CTF/教学） | 学习漏洞模式 | 每条问题带 CWE 知识讲解与修复示例 |

## 2. 功能需求（FR）

- **FR-1 多粒度审计**：函数级 / 文件级 / 工程级三层；输入支持单文件、目录（递归 *.py）、代码字符串。
- **FR-2 缺陷识别四类目**：安全漏洞(security)、逻辑错误(logic)、代码规范(style)、工程实践(engineering)。
- **FR-3 知识增强（RAG）**：审计时从缺陷知识库检索相关条目注入上下文；输出必须引用知识条目 ID（可溯源）。
- **FR-4 结果验证**：①证据回溯（行号/原文核验，防幻觉）②静态规则与模型结果交叉比对 ③置信度过滤 ④多次运行一致性指标。
- **FR-5 报告生成**：Markdown + JSON 双格式；每个问题含 定位/证据/分析/影响/修复建议/来源/置信度/检出方式。
- **FR-6 免密钥降级**：未配置 API Key 时静态规则引擎仍可独立工作（check 命令）。
- **FR-7 增量能力**（P1，D19 后做）：按文件哈希缓存已审结果，仓库复审只跑变更部分。

## 3. 输出契约（核心，验收以此为准）

每条问题（Issue）必备字段：
`rule_id, category, severity(4级), title, path, line_start/line_end, evidence(逐字原文), analysis(数据流论证), impact, fix(可操作), confidence(0~1), source(CWE链接), detector(static|llm|both), verified, votes`

severity 定义：
- critical：可被直接利用的 RCE/数据泄露
- high：明确缺陷，影响正确性或安全
- medium：有风险的设计/实现问题
- low：规范、可维护性

## 4. 非功能需求（NFR）

- **NFR-1 一致性**（关键问题4）：同一代码两次审计结果 Jaccard ≥ 0.8；temperature 固定 0.1。
- **NFR-2 误报控制**（关键问题3）：人工标注测试集上，precision ≥ 0.8（宁缺毋滥优先）；召回不设硬指标但 T2 类过度推断必须拦截。
- **NFR-3 性能**：函数级并发 4~8，单文件（<500 行）P50 ≤ 30s；纯静态模式秒级。
- **NFR-4 成本可控**：免费额度 100 万 token 支撑 ≥ 300 次函数级审计；启用用完即停。
- **NFR-5 可解释**：报告里每条问题都能点开看到引用的知识条目原文。
- **NFR-6 安全**：密钥只存 .env；审计样例库只用自写/开源代码。

## 5. 范围边界（第一阶段明确不做）

- ❌ Java/C++/JS 审计（parser 预留接口，申报书周期内以 Python 交付）
- ❌ Web 界面/CI 集成（结题形式是"项目软件+使用说明书"，CLI 达标；有余力 D19 后加）
- ❌ 自动修复（只给建议，不改用户代码——避免破坏性风险）
- ❌ 模型微调（用 API + RAG 路线，算力与数据不具备）

## 6. 验收标准（对应结题四阶段成果）

1. `python -m codeaudit audit <demo项目> -d function` 输出报告，预埋缺陷检出率 100%（examples 标准集）
2. 评测基准：`python -m codeaudit eval examples/bench --runs 3`，precision ≥ 0.8 且 recall ≥ 0.8
   （基准集 = examples/bench/：6 正样本 14 标注 + 8 干扰样本 0 预期；真实开源项目样本 10 月扩充至 ≥20）
3. 一致性：同输入 3 次运行的 eval 结果 stable_across_runs=True（D17 缓存使多轮评测近似免费）
4. 离线测试全绿 + 使用说明书（11 月）
